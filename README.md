# Finance Tracker

Web app simpel buat nyatet pengeluaran dan pemasukan bulanan. Udah support multi-user pake Supabase Auth, jadi data tiap user aman dan misah-misah.

## Fitur
- Catat pemasukan & pengeluaran
- Set target budget bulanan & target tabungan
- Dark mode
- Bisa diinstall ke HP (PWA)
- Multi-user (Supabase Auth & RLS)

## Tech Stack
- React + Vite
- Tailwind CSS v4
- shadcn/ui
- Supabase (PostgreSQL + Auth)
- Recharts buat grafik

## Cara Install

1. Clone repo ini
```bash
git clone https://github.com/irisu25/finance-tracker.git
cd finance-tracker
npm install
```

2. Setup Supabase
Buat project di [Supabase](https://supabase.com). Jalankan script SQL ini di SQL Editor Supabase buat bikin tabel dan setting security-nya:

```sql
CREATE TABLE transactions (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  amount NUMERIC NOT NULL,
  type TEXT NOT NULL,
  category TEXT,
  note TEXT,
  date DATE,
  user_id UUID REFERENCES auth.users(id)
);

CREATE TABLE user_settings (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  monthly_budget NUMERIC DEFAULT 0,
  savings_target NUMERIC DEFAULT 0,
  user_id UUID REFERENCES auth.users(id)
);

CREATE TABLE preorders (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  item_name TEXT NOT NULL,
  total_price NUMERIC NOT NULL,
  paid_amount NUMERIC DEFAULT 0,
  user_id UUID REFERENCES auth.users(id),
  created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

ALTER TABLE transactions ENABLE ROW LEVEL SECURITY;
ALTER TABLE user_settings ENABLE ROW LEVEL SECURITY;
ALTER TABLE preorders ENABLE ROW LEVEL SECURITY;

CREATE POLICY "Akses Transaksi" ON transactions FOR ALL USING (auth.uid() = user_id);
CREATE POLICY "Akses Pengaturan" ON user_settings FOR ALL USING (auth.uid() = user_id);
CREATE POLICY "Akses PO Merch" ON preorders FOR ALL USING (auth.uid() = user_id);
```

3. Bikin file `.env`
Bikin file `.env` di folder utama, isinya URL dan Anon Key dari project Supabase:
```env
VITE_SUPABASE_URL=url_supabase_kamu
VITE_SUPABASE_ANON_KEY=anon_key_supabase_kamu
```

4. Jalanin
```bash
npm run dev
```
